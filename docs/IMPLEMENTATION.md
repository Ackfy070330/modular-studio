# 0.1 实现与验收

日期：2026-10-12。当前交付是本机运行的前后端 MVP。

## 已实现的闭环

React Flow 功能图 → Blockly 表达式 → 蓝图校验与版本保存 → Node.js 源码生成 → 子进程执行 → SQLite 写入 → 节点级数据回传 → 查看源码与真实 Inspector 调试 → 生成页面预览与独立应用导出。

生成应用使用 Node.js 内置 HTTP 和 SQLite，无额外运行依赖。工作台使用 React、Fastify、本地 SQLite 和 Node Inspector；实现没有依赖规划中的 PostgreSQL、OpenTelemetry 或 DAP。

## 自动化验证

`npm test` 的前 8 项测试覆盖：

1. 拒绝断开的节点、循环、分叉和无效执行顺序。
2. 执行生成代码，确认修改表达式改变输出，确认真实数据库写入和失败时不写入。
3. 配置不能注入生成代码，页面中的用户文案正确转义。
4. 运行数据遮盖敏感字段并限制递归深度和大小。
5. 导入真实文件依赖，阻止越出项目目录的源码读取。
6. 真实 Node 子进程命中断点，读取作用域，单步、继续并完成流程。
7. 连续 8 次校验失败均保留失败节点，不误标后续节点为成功。
8. 使用本地模拟 API 校验请求协议、密钥处理、建议审核以及版本冲突。

`npm run build` 执行 TypeScript 检查和 Vite 构建。

## 本版边界

导入项目暂时只有静态分析，不自动安装依赖、执行导入的代码或采集任意项目运行数据。生成流水线的运行轨迹是阶段级追踪，表单/展示阶段不代表独立浏览器跨度。调试期间的耗时包含人为暂停。

智能体 API 尚无用户凭据，未做真实供应商端到端验证。当前适配是 Chat Completions 兼容协议，修改范围为已有蓝图节点配置，不等同于接通任意厂商编程智能体。

当前环境为本地开发；测试/生产环境、跨服务追踪、分支/循环、多人协作、远程权限、任意语言调试和完整开发沙箱仍在后续里程碑中。

基础版本验证：8 项测试通过，TypeScript/Vite 构建通过，依赖安装审计 0 项漏洞。升级静态文件插件后，已确认构建页面、脚本资源、健康检查和来源限制正常。

## 自定义内容增量验收

新增常驻“添加模块”按钮、模块选择器、自定义内容编辑器，以及可点击的连线编辑。自定义内容的创建、修改和生成均要求已配置 API Key；基础模块可继续使用。保存、导入和智能体应用路径共用后端校验，防止仅在界面限制。

新增 3 项自动化测试，总计 11 项通过。测试验证：无密钥及空白密钥被拒绝；自定义生成使用兼容 API 并校验返回；不支持的需求和危险字段被拒绝；自定义计算 total × 0.9 得到 180，连线映射后的 orderAmount=180 出现在下游输入；编辑文字后旧逻辑失效。模型调用使用本地测试服务，尚未配置真实供应商。

界面验收：常驻按钮打开模块选择器；无 API Key 可以添加内置数据校验模块（测试后已撤回）；自定义模块与点击连线均进入配置引导；引导可以打开 API 设置。HTTP 接口对无密钥的生成和自定义保存返回 428，项目内容不变。原有订单流程回归执行成功。
